Windows 程序：下载 ZIP、完整解压后运行 EXE。TEMU Invoice 需要 Microsoft Excel。

Chrome 插件：解压后在 `chrome://extensions` 开启开发者模式，加载含 `manifest.json` 的目录。

首次使用需联网并获得永恒终端X授权。更新前保存工作，待程序自然退出后替换；保留原有账号、配置和业务数据。桌面程序支持 OTA，Chrome 插件暂不支持 OTA。
