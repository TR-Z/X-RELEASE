CBP3499 V1 X：解压后双击唯一的 EXE。先在“下拉选项管理”添加或导入自己的客户公司和联系信息，再导入提单并核对识别结果，填写 Entry 和本次包裹明细后生成 PDF。提单识别在本机完成。

默认每次导出一份可编辑 PDF，可下拉选择固定内容 PDF。文件名按 Entry 编号保存，例如 `3499 NUP-00001234.pdf`；编号和数量保留前导 0，重名时自动增加序号。生成记录可拉取回填表页面继续修改。

公开包不含客户资料。首次在已有普通 V1 的同一 Windows 用户下运行时，只读复制其下拉选项和生成记录到 X 版独立目录；普通版和原数据保留。新电脑可导入自己导出的选项，或手动添加。

CBP3499 V1 X 接入现有永恒终端X，与其他程序分别审批、分别计期限；首次桌面试用为七天。正式授权成功同步后，离线可用至原批准到期日；续期或审批变更需联网刷新。
