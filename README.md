## 统一首次联网许可（2026-10-29）

本次客户端更新统一由永恒终端X签发首次联网许可；保留原界面、独立产品身份、原签名及数据位置。兼容验收范围见下文，正式发布状态以 GitHub Release 为准；更新静态下载包不会自动推送生产 OTA。

- ACELYNK Portable X 3.8.9X（build 2026102902）
- TEMU Invoice X 4.6.3X（build 2026102902）
- CBP3499 V1 X 1.0.7X（build 2026102902）
- FDA ITACS Checker X 3.1.1
- FDA Mail Sender X 3.0.3
- MAGAYA Batch Off X 1.0.1

现行客户端保留独立接入通知上报。拥有者配置永恒终端X 2.11.5通知接收器后，主后台正常关闭时仍可接收接入消息；设备身份、产品期限、数据路径和原签名保留。

三个新版桌面客户端的首次使用须联网，由同一永恒终端X的全局7天开关决定是否签发普通 customer 许可。开关关闭时，新凭据等待人工审批；客户端不再自行开始新的未签名离线7天。

旧未签名本地试用记录须联网补报原起点，经后台核对签发后只使用原剩余期限，不重新开始7天。旧已签名试用、正式和永久许可保留原身份与期限；有截止日的许可仍只离线有效至原截止日。原客户组、独立产品审批、设备密钥和配置保留。

Chrome 三个插件沿用原字节及同一后台开关，没有客户端本地或离线试用。后台规则不会追溯重置旧记录。

新版首次联网需要主后台支持独立 `/v2/device/capabilities` 协议及 `server-auto7-v1` 能力；原 health 协议不变。缺少能力时不退回旧首次试用路径，已有有效签名许可仍按原截止离线使用。手机最终实装与当前主后台兼容性按下列独立证据核对。

桌面三个包保留原 OTA 能力和稳定入口：更新等待任务结束与程序自然退出后再替换，只恢复程序、不回滚授权或用户数据、不重放业务。Chrome插件仍不支持OTA。本次仅更新静态分发包，不发布生产 OTA 清单；桌面客户端目录在正式远端包逐字节验证后同步。

## 保留的 CBP3499 业务功能基线（1.0.6X / build 2026102901）

- 新增明细入口支持选择已打开的 Chrome 分单窗口，另提供复制文字导入；只带入 HOUSE、REF、CARTON 和 Description。
- 每条新增明细默认 1 Parcel；导入不读取数量、单位或单价，已有手动数量和单位保留。
- 英文品名按出现顺序去重，五项以内全部保留，超过五项自动取前三项；可继续手动补充。
- 有 Entry 时按 3499 Entry命名；未填 Entry 时使用上方 MAWB，所有编号保留前导零。
- 修复提单核对窗口出口公司识别、Firm Code 注释括号残留和 Port 多余括号；生成记录可拉取恢复。
- 默认单份可编辑 PDF，下拉可选固定 PDF；保留原授权、通知及 OTA 功能。
- 本轮已验证复制文字导入及最终签名程序启动、PDF和历史恢复；真实业务窗口直接读取尚未完成实测。

普通版与 X 版都增加用户请求的读取系统明细业务导入按钮；两版业务界面保持一致，X 不增加额外授权或 OTA 控件。

CBP3499 当前附件为 `OTA.cbp3499-x.windows-x64.stable.zip`，解压后只有稳定入口 `CBP3499 V1 X.exe`。本次同时更新 ACELYNK 和 TEMU 的授权客户端 SDK；其余当前插件 ZIP 保留原字节。原产品身份、签名、接入通知、授权期限及数据位置保留。

本次验收摘要位于 manifest 的 `server_auto7_client_update`，当前分发资产绑定实际版本、asset ID 和 SHA256。`cbp3499_v1_x_update_20261029` 及其他历史段落保留各自旧包范围，不作为本轮新包通过的证据。

## 使用说明

ACELYNK V3.8.9X 保留原业务行为：暂停后继续会在原 Chrome 中重新登录过期会话，
确认后执行剩余 Entry；已完成条目不重复。暂停期间仅提示一次，
不重复刷新等待日志；实际恢复后显示本次暂停总时长。

CBP3499 V1 X：解压后双击唯一的 EXE。先在“下拉选项管理”添加或导入自己的客户公司和联系信息，再导入提单并核对识别结果，填写 Entry 和本次包裹明细后生成 PDF。提单识别在本机完成。

默认每次导出一份可编辑 PDF，可下拉选择固定内容 PDF。文件名按 Entry 编号保存，例如 `3499 NUP-00001234.pdf`；编号和数量保留前导 0，重名时自动增加序号。生成记录可拉取回填表页面继续修改。

CBP3499 1.0.7X 保留用户明确授权的下拉选项默认信息，仅限选项；不含生成历史、密码、私钥或授权状态。已有本地下拉选项优先并保留。新电脑可继续导入或维护自己的选项。

CBP3499 V1 X 接入现有永恒终端X，与其他程序分别审批、分别计期限；新版首次使用由联网后台的全局7天开关决定，客户端不自行创建新的未签名试用。已有后台签发许可仍按原批准到期日离线有效；续期或审批变更需联网刷新。

所有现行客户端包均保留在最新 Release 中。

CBP3499 V1 X 界面沿用普通版，不增加试用、授权状态或刷新授权控件。

FDA Mail Sender V3X：打开网页时保持隐藏，点击 Chrome 插件图标后打开。版本与授权身份保留，邮件发送流程不变。
